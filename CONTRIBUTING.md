# Contributing

Read [AGENTS.md](AGENTS.md) for the working agreement and [engineering standards](docs/engineering.md) for language, architecture, validation and delivery rules. Product behavior starts in [requirements](docs/requirements.md); acceptance evidence lives in [validation](docs/validation.md).

Keep contributions focused and in English. Preserve upstream notices, test meaningful behavior and distinguish host/build checks from device results. Follow the setup and test commands in [README.md](README.md). Publish or deploy only within the user's requested scope.
